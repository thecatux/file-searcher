# File Searcher

A lightweight desktop application for searching files by name or searching text inside files. It supports regular expressions for content searches, case-sensitive matching, result limits, and cancellable searches.

## Requirements

- Rust and Cargo

## Run

```sh
cargo run
```

## Build

```sh
cargo build --release
```
